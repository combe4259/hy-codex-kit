# playbook: checkpoint

기능 하나를 마칠 때마다 사용한다.

1. 테스트를 실행한다. 출력 마지막 요약을 확인한다.
2. 실행 중인 서비스라면 스모크 확인(AGENTS.md의 명령)을 실행한다.
3. 실패하면 여기서 멈추고 원인을 고친 뒤 1번부터 다시 한다. 테스트를 고쳐서 통과시키지 않는다.
4. 통과하면:
   - `docs/PROGRESS.md`에서 해당 기능을 "통과"로 바꾸고 확인 방법을 적는다.
   - `docs/VERIFICATION.md` 표에 한 줄 추가한다 (확인한 것, 방법, 결과, 명령·출력 요약).
   - 이번에 내린 설계 결정이 있으면 `docs/DECISIONS.md`에 추가한다.
5. `git diff --stat`으로 변경 범위를 확인하고 커밋한다 (`feat:` 등 형식, 왜를 포함).
6. 사용자에게 3줄로 보고한다: 무엇을 했나 / 왜 이렇게 했나 / 어떻게 확인했나.
