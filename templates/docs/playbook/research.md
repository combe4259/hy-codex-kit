# playbook: research

모르는 도메인 개념을 빠르게 이해할 때 사용한다.

1. 조사할 개념을 3개 이내로 좁힌다. 과제 해결에 직접 필요한 것만.
2. 웹 검색이나 fetch로 신뢰할 수 있는 출처(위키피디아, 공식 문서, 교재 수준 자료)를 1~2개 읽는다. 페이지 전체를 붙여넣지 말고 필요한 부분만 요약한다.
3. 개념마다 아래 형식으로 `docs/GLOSSARY.md`에 추가한다.
   - 한 줄 정의
   - 이 과제에서 왜 중요한가
   - 출처 URL
4. 조사 결과가 설계에 영향을 주면 `docs/DECISIONS.md`에 근거로 남긴다.
5. 확실하지 않은 내용은 "확인 필요"로 표시하고, 실무자에게 물을 질문으로 넘긴다.
6. 마지막에 비전공자가 이해할 수 있게 5줄 이내로 설명한다.
